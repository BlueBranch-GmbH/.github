# .github

Dieses Repository enthält die organisationsweiten Vorgaben der
[BlueBranch GmbH](https://github.com/BlueBranch-GmbH) auf GitHub.

| Datei | Wirkung |
|---|---|
| [`profile/README.md`](profile/README.md) | Wird auf der Profilseite der Organisation angezeigt: <https://github.com/BlueBranch-GmbH> |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Gilt als Beitragsleitfaden für jedes Repository der Organisation, das keinen eigenen hat |
| [`SECURITY.md`](SECURITY.md) | Gilt als Sicherheitsrichtlinie für jedes Repository der Organisation, das keine eigene hat |

GitHub zieht diese Dateien automatisch heran. Ein Repository, das eine gleichnamige Datei selbst
mitbringt, hat Vorrang – die Dateien hier sind also der Standard, nicht die Vorschrift.

Hier gehört **kein** Projektcode hinein.
